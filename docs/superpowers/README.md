# Specs e planos históricos

As pastas `specs` e `plans` contêm registros datados das decisões e etapas de
implementação. Um item descrito como futuro ou pendente nesses arquivos pode
já ter sido concluído, substituído ou removido.

Use o [`README` da raiz](../../README.md), o [`CLAUDE.md`](../../CLAUDE.md) e as
documentações técnicas dos serviços para entender o comportamento atual. Os
arquivos históricos devem ser alterados apenas para corrigir o próprio
registro, não para representar o estado vigente do produto.
